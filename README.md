# Whisper Subtitle Generator

Generate accurate subtitles (SRT/VTT) from audio or video files using [OpenAI Whisper](https://github.com/openai/whisper). Ideal for content creators, educators, and accessibility tools.

## 🔧 Features

- ✅ Automatic transcription using Whisper
- ✅ Supports multiple input formats (MP3, MP4, WAV, etc.)
- ✅ Generates `.srt` and `.vtt` subtitle formats
- ✅ Language detection and multilingual support
- ✅ Easy-to-use CLI
- ✅ Batch processing support
